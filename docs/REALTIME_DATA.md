# SpaceGuard AI — Real-Time Data

## Data Source Classification

SpaceGuard strictly classifies every data source by its actual update behavior. No source is misrepresented.

### Historical
Data from completed missions or finalized datasets. Not updated.

| Source | Classification |
|--------|---------------|
| NASA SMAP/MSL dataset | Historical |
| OPS-SAT AD dataset | Historical (mission ended 2024) |

### Near-Real-Time
Data that updates when new observations or measurements are available, but not continuously. Updates depend on external factors (ground station passes, observation scheduling).

| Source | Classification | Update Frequency |
|--------|---------------|------------------|
| SatNOGS telemetry | Near-real-time (observation-dependent) | Per ground station pass |
| CelesTrak orbital data | Near-real-time | Multiple times daily |
| NOAA SWPC | Near-real-time | 1-minute to 3-hour intervals |
| NASA DONKI | Near-real-time (event-driven) | Per event occurrence |

**Important**: SatNOGS data is described as "observation-derived telemetry" or "opportunistic telemetry". It is NOT continuous real-time spacecraft telemetry. Coverage depends on:
- Ground station availability
- Satellite visibility window
- Decoder availability
- Observation scheduling

### Simulated
Data generated by SpaceGuard's internal telemetry simulator.

| Source | Classification | Update Frequency |
|--------|---------------|------------------|
| SpaceGuard simulator | Simulated | Configurable (1-60s) |

### Live
Direct telemetry feed from active spacecraft. **Not available in MVP** — would require mission operator integration.

## Real-Time Pipeline

```
Telemetry Source
       │
       ▼
  Ingestion Service (polls or receives)
       │
       ▼
     Backend (validates, normalizes)
       │
       ├──▶ MongoDB (persistence)
       ├──▶ Anomaly Engine (detection)
       └──▶ Socket.IO → Frontend (live display)
```

## Source Failure Handling

| Source | If Unavailable |
|--------|---------------|
| SatNOGS | "SatNOGS data unavailable — last successful fetch: {timestamp}" |
| NOAA SWPC | "Space weather data unavailable" |
| NASA DONKI | "Environmental event data unavailable" |
| CelesTrak | "Orbital data unavailable — using last known state" |
| Simulator | "Simulation stopped" |

Never silently substitute fake data for a failed source.
